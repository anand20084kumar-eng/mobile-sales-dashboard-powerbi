# 📊 Mobile Sales Dashboard – Power BI

An interactive Mobile Sales Dashboard developed using Microsoft Power BI to analyze sales performance, customer trends, and key business insights.

## 📌 Project Overview

This project focuses on analyzing mobile sales data through an interactive and visually appealing Power BI dashboard.

The dashboard helps users understand sales performance, identify trends, and explore important business metrics using different visualizations and filters.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

- Interactive sales performance analysis
- Monthly and overall sales trends
- Customer and product analysis
- Key performance indicators (KPIs)
- Interactive filters and slicers
- Visual representation of business data
- Easy-to-understand dashboard layout

## 🔍 Key Insights

The dashboard provides insights into:

- Overall sales performance
- Sales trends over time
- Customer purchasing patterns
- Product and mobile sales performance
- Important business KPIs
- Areas that can support better business decisions
